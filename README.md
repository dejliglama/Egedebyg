# Egedebyg - Tømrer & Byggefirma

Professional carpenter and construction company website built with HTML5, CSS3, and responsive design.

## Features

- **Responsive Design**: Optimized for desktop, tablet, and mobile devices
- **Professional Layout**: Clean, modern design with professional color scheme
- **Service Showcase**: Dedicated sections for different carpenter services
- **Project Gallery**: Visual showcase of completed projects
- **Contact Information**: Complete contact details and contact form
- **Danish Language**: Website content in Danish for local market

## Services

- **Tømrerarbejde**: Traditional carpentry work with focus on quality and craftsmanship
- **Renovering**: From minor repairs to large renovation projects  
- **Nybyggeri**: Complete new construction from foundation to finished house
- **Tagarbejde**: Installation and repair of roofs with all materials

## Getting Started

1. Open `index.html` in your web browser
2. Or serve locally with: `python3 -m http.server 8000`
3. Navigate to `http://localhost:8000`
