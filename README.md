# Egedebyg

En moderne, responsiv one-page website for Egedebyg - din pålidelige partner inden for byggeri og construction.

## Funktioner

- 🏗️ Moderne, professionelt design
- 📱 Fuldt responsiv (mobil, tablet, desktop)
- ⚡ Hurtig indlæsning og optimeret ydeevne
- 🎨 Smooth scrolling og animationer
- 🌐 Klar til Netlify deployment

## Teknologier

- HTML5 med semantisk markup
- CSS3 med Grid og Flexbox
- Vanilla JavaScript
- Optimeret til Netlify hosting

## Deployment til Netlify

### Automatisk deployment

1. Forbind dette GitHub repository til Netlify
2. Netlify vil automatisk deploye fra `main` branch
3. Build kommando: Ingen påkrævet (statisk HTML)
4. Publish directory: `.` (root)

### Manuel deployment

1. Download eller klon repositoryet
2. Upload filerne til Netlify via drag-and-drop i Netlify dashboard

## Lokal udvikling

For at køre sitet lokalt:

```bash
# Klon repositoryet
git clone https://github.com/dejliglama/Egedebyg.git

# Naviger til mappen
cd Egedebyg

# Åbn index.html i din browser eller brug en lokal server
# For eksempel med Python:
python -m http.server 8000

# Eller med Node.js:
npx serve .
```

## Tilpasning

- **Indhold**: Rediger `index.html` for at opdatere tekst og struktur
- **Design**: Modificer `styles.css` for at ændre farver, skrifttyper og layout
- **Funktionalitet**: Tilpas `script.js` for ekstra interaktivitet
